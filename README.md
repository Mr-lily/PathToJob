# 薪途 PathToJob

> 求职不再焦虑，用数据驱动你的每一次投递。

## 这是什么

薪途是一个帮你**高效找工作**的工具。它能自动抓取你在招聘网站上看到的岗位信息，集中到一个看板里管理，并用 AI 帮你分析每个岗位是否适合你。

**简单来说**：你在 Boss直聘 / 51job / 猎聘 / 智联 / 鱼泡上看到合适的岗位，点一下就能保存到看板，AI 会告诉你这个岗位和你的匹配度、面试该怎么准备。

## 核心功能

### 一键抓取岗位
在任意招聘网站的岗位详情页，点击浏览器扩展按钮，岗位信息自动保存到你的看板。支持 Boss直聘、前程无忧、猎聘、智联招聘、鱼泡直聘 5 个平台。

### AI 智能分析
每个抓取的岗位都会自动生成分析报告：
- **适配指数**：根据你的简历和求职意向，评估岗位匹配度（0-100 分）
- **求职难度**：AI 判断这个岗位的竞争程度和入职难度
- **推荐指数**：综合薪资、通勤、适配度的加权评分

### 深度分析（重点岗位）
标记为「重点」的岗位会触发更深入的分析：
- 岗位职责拆解
- 公司背景调研
- 面试准备策略

### 投递进度管理
每个岗位都可以标记投递状态，从「未投递」到「已入职」全流程跟踪。支持批量操作，一目了然。

### 通勤时间计算
设置你的住址后，自动计算每个岗位到公司的通勤时间（驾车 / 公交 / 步行），帮你排除通勤太远的机会。

### 简历匹配
上传你的简历，AI 分析会结合你的实际经历，给出更精准的适配评分。

### 手机查看
电脑上操作看板，手机也能随时查看岗位、修改投递状态、添加备注。

## 谁适合用

- 正在找工作的求职者，尤其是同时投递多个岗位时
- 想要系统管理投递进度，而不是在收藏夹里翻来翻去
- 希望有 AI 帮忙分析岗位是否值得投、面试怎么准备

## 快速开始

### 1. 安装浏览器扩展

下载扩展 → 解压得到 `bossdive` 文件夹 → 按下面步骤操作：

**Edge 浏览器**：地址栏输入 `edge://extensions` → 打开左下角「开发者模式」→ 点「加载已解压的扩展」→ 选择 `bossdive` 文件夹

**Chrome 浏览器**：地址栏输入 `chrome://extensions` → 打开右上角「开发者模式」→ 点「加载已解压的扩展」→ 选择 `bossdive` 文件夹

### 2. 注册账号

打开看板页面，输入邀请码、用户名、密码完成注册。

### 3. 登录扩展

点击浏览器工具栏的扩展图标 → 输入用户名和密码 → 登录。

### 4. 开始抓岗位

打开任意招聘网站 → 点开岗位详情页 → 点击页面右下角蓝色「+ 抓取岗位」按钮 → 完成！

## 电脑 vs 手机

| 功能 | 电脑 | 手机 |
|------|------|------|
| 抓取新岗位 | ✅ | ❌ |
| 查看岗位列表 | ✅ | ✅ |
| 修改投递状态 | ✅ | ✅ |
| AI 分析 | ✅ | ✅ |
| 添加备注 | ✅ | ✅ |
| 批量操作 | ✅ | ✅ |

> 手机浏览器打开看板地址即可使用，但抓取岗位只能在电脑端操作。

## 常见问题

**抓取没反应？**
确保你在岗位详情页（不是列表页），刷新页面后重试。

**登录后看板是空的？**
按 Ctrl + F5 强制刷新页面。

**想换账号？**
点击看板右上角退出登录。

## 技术栈

- **后端**：Python（SQLite 数据库）
- **前端**：纯 HTML + CSS + JavaScript（无框架依赖）
- **扩展**：Chrome Extension Manifest V3
- **AI**：DeepSeek API（需要自己申请 Key）
